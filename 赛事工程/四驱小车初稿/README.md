# 四驱小车初稿

赛事工程 · 浙江理工大学科技与艺术学院第五届机器人大赛（2026-12-03）参赛车第一版工程。

基于 **STM32F103C8T6 + 标准外设库**，结构沿用江协科技工程模板（Start / Library / System / Hardware / User），
对应 B 站《【四驱智能小车】-STM32主控-循迹-避障-2.4G遥控》第 22~23 集的内容：
**GPIO 控制正反转 + 定时器 PWM 调速**。

## 当前实现了什么

| 功能 | 文件 |
| --- | --- |
| TB6612 / L298N 双通道驱动，四驱（左右各并两个电机） | `Hardware/Motor.c` |
| TIM3 双通道 PWM，10kHz，占空比 0~100 | `Hardware/Motor.c` |
| 前进 / 后退 / 差速转弯 / 原地转 / 停车 | `Hardware/Motor.c` |
| 按键触发演示、OLED 显示状态 | `User/main.c` |

## 接线表

| 功能 | TB6612 | L298N | STM32 |
| --- | --- | --- | --- |
| 左轮调速 | PWMA | ENA | PA6（TIM3_CH1） |
| 左轮方向 1 | AIN1 | IN1 | PB12 |
| 左轮方向 2 | AIN2 | IN2 | PB13 |
| 右轮调速 | PWMB | ENB | PA7（TIM3_CH2） |
| 右轮方向 1 | BIN1 | IN3 | PB14 |
| 右轮方向 2 | BIN2 | IN4 | PB15 |
| 使能 | STBY → 拉高 | 不用接 | PB5 |
| OLED | — | — | PB8(SCL) / PB9(SDA) |
| 按键 KEY1 / KEY2 | — | — | PB1 / PB11 |

**电源**：电池正极接驱动板 VM，驱动板 GND 与单片机 GND 必须共地。
电机电源千万不要从单片机 5V 取，也不要经过面包板。

## 第一次上电怎么测

1. **把车架空**（轮子离地），再烧程序，避免车冲下桌子。
2. 按 KEY1，观察四个轮子的转向：前进时四个轮子都应往前转。
3. 如果有轮子反了，改 `Hardware/Motor.h` 里的 `MOTOR_LEFT_REVERSE` / `MOTOR_RIGHT_REVERSE`
   为 1，重新编译，不用拆线。
4. 观察 30% / 60% / 100% 三档速度差别，确认 PWM 生效。
5. 确认无误后再放地上跑。

## 卡住时按这个顺序查

1. **车完全不动** → 先量驱动板 VM 有没有电压；再确认 PB5（STBY）是不是高电平。
2. **只有一个轮子转** → 查对应通道的方向脚和电机线；四驱是左右各并两个电机，并线接反会导致一个正一个反。
3. **轮子转但没劲** → 电池电压低于 7V，充电；或者 PWM 占空比太小。
4. **一动就复位/OLED 花屏** → 电源问题，电机和单片机共地不良，或电池内阻大，加 470µF 电解电容。
5. **编译报错找不到 Motor.h** → 确认 Keil 里 Hardware 分组下有 Motor.c，且 C/C++ 的 Include Paths 含 `.\Hardware`。
